# Nimma.codes redesign: overdrachtspakket

Het ontwerp voor de nieuwe Nimma.codes-site (richting "A2 Blauwdruk"), klaar om in code te bouwen.

| Bestand | Wat |
|---|---|
| `index.html` | Homepage, statische export van het ontwerp. Open lokaal in de browser en maak het venster smaller om tablet en mobiel te zien. |
| `code-of-conduct.html` | Gedragscode-pagina in dezelfde stijl. |
| `assets/site.css` | Alle stijlen: classes, breakpoints, animaties. Geen framework. |
| `assets/img/` | Logo, skyline en illustraties als SVG. |
| `docs/HANDOFF.md` | De spec: tokens, breakpoints, componenten, animaties, toegankelijkheid en open punten. Begin hier. |
| `docs/adr/0001-hugo-en-meetup-feed.md` | Voorstel voor de stack en voor het automatisch tonen van de volgende meetup. |

Het ontwerpcanvas (desktop, tablet, mobiel, stijlgids en Code of Conduct) staat op Claude: https://claude.ai/code/artifact/5599d030-6c95-45db-b835-f33d19ab7feb

Advies: zet deze map in de repo onder `docs/design/` en bouw van daaruit verder.
